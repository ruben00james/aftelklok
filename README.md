# Aftelklok

Aftelklok voor de dienst van ZDA Den Bosch "De Drie Engelen": dezelfde klok voor de livestream en voor de zaal.

- Zaal (beamer, telefoon): open de website, vul in hoe laat de dienst begint en klik op "Start de klok". Klik daarna één keer voor volledig scherm.
- Direct naar een tijd: voeg `?zaal&tot=11:00` toe aan het adres.
- Andere tekst boven de klok: vul hem in op het instelscherm, of voeg `&kop=Het%20middagprogramma%20begint%20over` toe aan het adres.
- De klok telt af naar een kloktijd, dus elk apparaat toont dezelfde resterende tijd zolang zijn eigen klok goed staat.

Alle instellingen staan bovenin `huisstijl/aftelklok.html`. Lettertype: Montserrat (SIL Open Font License, zie `fonts/OFL.txt`).
